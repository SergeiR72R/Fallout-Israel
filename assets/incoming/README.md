# Входящие ассеты

Сюда загружаются картинки, видео и модели из Google Flow и других генераторов. Подпапки и имена файлов — по таблице в конце [docs/PROMPTS.md](../../docs/PROMPTS.md):

- `backgrounds/` — фоны локаций
- `characters/` — развороты персонажей
- `models/` — 3D-модели и анимации Mixamo
- `portraits/` — портреты и видео «говорящих голов»
- `icons/` — иконки предметов
- `video/` — вступительный ролик
