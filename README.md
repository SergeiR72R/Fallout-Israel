# Хамсин

Изометрическая ролевая игра о постъядерном Израиле. Геймплей, механики и вид — как в Fallout 1/2, сеттинг свой.

**Статус:** прототип 0.2. Фоны, портреты, иконки, карта мира и вступление нарисованы в Google Flow ([docs/PROMPTS.md](docs/PROMPTS.md)), персонажи отрендерены из Blender.

## Что уже есть

- Изометрия 2:1 (поворот 45°, наклон 30°) — в ней стабильно рисует Flow; точный ракурс Fallout 2 включается двумя константами в `src/config.ts`. Гексовая сетка, прокрутка краями экрана.
- «Профиль»: 7 характеристик, 18 навыков, 3 отмеченных навыка, 6 черт характера — формулы Fallout 2.
- Пошаговый бой: очки действия, очерёдность, остаток ОД в класс брони, прицельные выстрелы по частям тела, криты, порог и сопротивление брони, перезарядка, две руки.
- Исследование в реальном времени, переход в бой, когда враг замечает героя.
- Диалоги с ветками, скрытыми проверками навыков и репликами для героя с низким Интеллектом.
- Задание, награда, опыт, уровни, распределение очков навыков, перки каждые три уровня.
- Инвентарь, обыск ящиков и трупов, взлом замков, первая помощь.
- Интерфейс в духе Fallout: нижняя панель, монитор сообщений, лампочки ОД, счётчики ОЖ/КБ, экран персонажа, «Кешер» (аналог Pip-Boy).
- Полупрозрачные стены, когда они закрывают героя (как в Fallout 2).
- Нарисованная карта мира северного Негева: туман войны, путешествие со временем, дни воды миклата, случайные встречи с проверкой Выживания. Каждая встреча (скорпионы, мародёры, караван, заправка) — своя нарисованная локация.
- Вступительный ролик из шести сцен с субтитрами.
- Силуэт героя сквозь стены и навесы нарисованного фона.
- Торговля как в Fallout: цены зависят от навыка «Торговля», торгуют Батья и караванщик Мордехай.
- Персонажи — спрайты, отрендеренные в Blender (см. [docs/SPRITES.md](docs/SPRITES.md)).
- Сохранение и загрузка (F6/F9), редактор проходимости (F10).
- Конвейер для нарисованных фонов: заготовка → перерисовка во Flow → фон с невидимыми «заслонками глубины».

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run guides       # после build: эталонные картинки для Flow в docs/guides/
```

`?quick` в адресе — сразу в игру с готовым героем, без меню.

## Устройство кода

| Папка | Что внутри |
|---|---|
| `src/core` | гексовая математика, поиск пути, анимации |
| `src/rules` | характеристики, навыки, предметы, формулы боя |
| `src/world` | рендер, камера, локация, модели, персонажи |
| `src/game` | игровая логика: бой, ИИ, взаимодействие, сохранения |
| `src/ui` | интерфейс, меню, создание персонажа, звуки |
| `src/data` | локации, персонажи, диалоги, задания |
| `src/guide.ts` | рендер эталонов для генерации ассетов |
